# Esquemas de maniobras

Corazón esquemático en OAI ~30° con el sistema de conducción (`corazon.py`) y dos paneles por ficha (`esquemas.py`).

    python3 esquemas.py <carpeta de salida> [claves]
    node ../simulador/png.js <carpeta de salida>

Después se pasan a JPG de 1500 × 1000 en `figs/esq/<clave>.jpg`. La clave es la de la ficha (M en index.html).
